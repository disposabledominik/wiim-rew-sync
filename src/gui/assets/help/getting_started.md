# Getting Started

Welcome to WiiM ↔ REW PEQ Sync Tool! This guide will help you get started
with applying room correction to your WiiM device.

## What You Need

- A WiiM device connected to your local network
- Room EQ Wizard (REW) measurements exported as a text file, or REW running
  with its API enabled

## Quick Start

1. **Connect** — The app will automatically discover WiiM devices on your
   network. Select the device you want to configure.
2. **Choose EQ Type** — Select Parametric EQ (per-input) or RoomFit
   (all inputs), depending on your device's capabilities.
3. **Select Source** — For PEQ, choose which audio input to configure.
4. **Load Filters** — Import a REW file, pull filters from REW's API, or
   pull the current config from your device.
5. **Review & Push** — Preview your filters, then push them to the device.

That's it! The wizard guides you through each step.
